🎨 OpenAI Image Generation API Reference
🔹 1. Create Image
Endpoint:
POST https://api.openai.com/v1/images/generations
Generates an image from a text prompt.

Required
prompt (string) – Description of the desired image.
Max length:

gpt-image-1: 32,000 chars

dall-e-3: 4,000 chars

dall-e-2: 1,000 chars

Optional Parameters
Parameter	Description
model	One of dall-e-2 (default), dall-e-3, gpt-image-1
n	Number of images (1–10). Only n=1 supported for dall-e-3
size	Sizes vary by model:
gpt-image-1: 1024x1024, 1536x1024, 1024x1536, or auto
dall-e-2: 256x256, 512x512, 1024x1024
dall-e-3: 1024x1024, 1792x1024, 1024x1792
background	For gpt-image-1: transparent, opaque, or auto
output_format	Only for gpt-image-1: png (default), jpeg, webp
output_compression	Only for gpt-image-1 with webp/jpeg. 0–100, default 100
quality	gpt-image-1: high, medium, low, auto
dall-e-3: hd, standard
dall-e-2: standard
response_format	url (default) or b64_json. gpt-image-1 always returns b64_json
moderation	For gpt-image-1: low or auto
user	Unique user identifier for abuse tracking

Example
bash
Copy
Edit
curl https://api.openai.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -d '{
    "model": "gpt-image-1",
    "prompt": "A cute baby sea otter",
    "n": 1,
    "size": "1024x1024"
  }'
🔹 2. Edit Image
Endpoint:
POST https://api.openai.com/v1/images/edits
Creates edited or extended images using source images and a prompt.

Required
image:

gpt-image-1: up to 16 images (png, jpg, webp, < 25MB)

dall-e-2: 1 square png, < 4MB

prompt:

dall-e-2: max 1,000 characters

gpt-image-1: max 32,000 characters

Optional Parameters
Parameter	Description
model	One of dall-e-2 (default), gpt-image-1
background	Same as in generation
mask	PNG <4MB indicating editable areas
n	Number of images (1–10)
quality	gpt-image-1: high, medium, low, auto; dall-e-2: standard
size	Same size options as in generation
response_format	url or b64_json. gpt-image-1 returns b64_json only
user	Unique user identifier

Example
bash
Copy
Edit
curl -X POST "https://api.openai.com/v1/images/edits" \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -F "model=gpt-image-1" \
  -F "image[]=@body-lotion.png" \
  -F "image[]=@bath-bomb.png" \
  -F "image[]=@incense-kit.png" \
  -F "image[]=@soap.png" \
  -F 'prompt=Create a lovely gift basket with these four items in it'
